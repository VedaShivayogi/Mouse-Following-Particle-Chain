#  Mouse-Following Particle Chain

An interactive visual animation where a chain of particles smoothly follows the mouse cursor in real time. Built using **pure HTML, CSS, and JavaScript**, this project demonstrates motion smoothing, trailing effects, and dynamic color transitions.


## ✨ Features

- 🎯 Real-time mouse-following interaction  
- 🔗 Smooth particle chain motion  
- 🌈 Dynamic color gradient effect  
- ⚡ High-performance animation using `requestAnimationFrame()`  
- 🧩 No external libraries required  
- 🖥️ Fullscreen immersive experience  


## 🎮 Demo

Move your mouse across the screen to see the particle chain smoothly follow your cursor path.

> Ideal for **creative coding**, **UI animations**, and **frontend practice**.
